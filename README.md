# Isha Sojitra — Portfolio

A responsive Next.js and TypeScript portfolio for an Odoo backend developer,
with a filtered gallery covering 17 Odoo project workspaces. Gallery artwork is
illustrative and based on each project's features, rather than copied
client/demo screenshots. Each project card opens an animated case-study page
with its context, approach, module-by-module functionality, and scope notes for
bundled or third-party components. The main navigation opens dedicated Work,
Services, Expertise, Journey, and Contact pages. The Services page presents
three Odoo-focused offerings. The homepage provides concise previews of each
section and links to the dedicated pages for more detail.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `NEXT_PUBLIC_SITE_URL` to the deployed site URL when publishing so social
sharing metadata points to the correct Open Graph image.
